# Simple Web Browser

A desktop web browser application developed using **C# and Windows Forms**.

## Features

* Send HTTP/HTTPS requests and display webpage content
* Display HTTP response status codes and webpage titles
* Reload pages and set a custom homepage
* User authentication and registration
* Add, name, navigate to, and delete bookmarks
* Maintain persistent browsing history
* Navigate backward and forward through history
* Extract and display five URLs from a webpage
* Persist user preferences, bookmarks, and history using SQLite
* Asynchronous HTTP operations for a responsive user interface

## Technologies

* C#
* .NET Framework
* Windows Forms
* SQLite
* System.Net.Http
* Html Agility Pack
